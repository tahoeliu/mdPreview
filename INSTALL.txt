mdPreview — Install / 安装
==========================

English
-------
mdPreview is free, open-source software. It is signed with an ad-hoc code
signature instead of a paid Apple Developer certificate, so macOS may show
"mdPreview cannot be opened" the first time if the app arrived through a web
browser or AirDrop. This is expected. Pick ONE of the options below.

Option A (easiest, no prompt): one-line installer
  Open Terminal and run:

    curl -fsSL https://raw.githubusercontent.com/tahoeliu/mdPreview/main/scripts/get.sh | bash

  It downloads the latest release, verifies its signature and checksum, and
  installs it into /Applications. Files downloaded this way are not blocked by
  macOS. You can read the script first at the address above.

Option B: drag and drop (this disk image)
  1. Drag mdPreview.app onto Applications.
  2. Open mdPreview from Applications. If macOS blocks it:
     - macOS 15 and later: open System Settings > Privacy & Security, scroll to
       Security, click "Open Anyway" next to mdPreview, then confirm.
     - macOS 13 and 14: Control-click mdPreview > Open > Open.
  You only need to do this once.

Option C: Homebrew
    brew install --cask --no-quarantine tahoeliu/tap/mdpreview

Option D (advanced): clear the download flag yourself
    xattr -dr com.apple.quarantine /Applications/mdPreview.app
  Only do this for a copy you downloaded from the official project page.

Make it your default Markdown viewer
  Select any .md file in Finder > File > Get Info > Open with > mdPreview >
  Change All…

Help: https://github.com/tahoeliu/mdPreview/issues

中文
----
mdPreview 是免费的开源软件。它使用 ad-hoc 代码签名，而不是付费的 Apple 开发者证书，
所以通过浏览器或隔空投送获得应用时，macOS 第一次可能提示“无法打开 mdPreview”。
这是正常现象，从下面任选一种方式即可。

方式 A（最简单，不会弹窗）：一行命令安装
  打开“终端”，运行：

    curl -fsSL https://raw.githubusercontent.com/tahoeliu/mdPreview/main/scripts/get.sh | bash

  它会下载最新版本，校验签名和校验和，再安装到“应用程序”。用这种方式下载的文件
  不会被 macOS 拦截。你可以先在上面的地址阅读脚本内容。

方式 B：拖拽安装（本磁盘映像）
  1. 把 mdPreview.app 拖到 Applications。
  2. 从“应用程序”打开 mdPreview。如果被 macOS 拦截：
     - macOS 15 及以上：打开“系统设置 > 隐私与安全性”，滚动到“安全性”，
       点击 mdPreview 旁的“仍要打开”，再确认。
     - macOS 13、14：按住 Control 点按 mdPreview > 打开 > 打开。
  只需要操作这一次。

方式 C：Homebrew
    brew install --cask --no-quarantine tahoeliu/tap/mdpreview

方式 D（进阶）：自己清除“下载来源”标记
    xattr -dr com.apple.quarantine /Applications/mdPreview.app
  仅对从官方项目页面下载的副本这样做。

设为默认 Markdown 阅读器
  在“访达”中选中任意 .md 文件 > 文件 > 显示简介 > 打开方式 > mdPreview >
  全部更改…
