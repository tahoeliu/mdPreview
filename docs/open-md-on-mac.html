How to open a .md file on Mac

A .md file is plain-text Markdown. Macs can open it, but by default you see raw symbols such as #, ** and | instead of a formatted page. Here are three ways to fix that.

1. Use mdPreview (free, recommended)

mdPreview is a free, open-source Markdown viewer and editor for macOS 13 or later, on Apple silicon and Intel Macs. Install it, then double-click any .md file. It opens as a clean page with headings, tables, task lists, maths and diagrams. Nothing is uploaded: it works offline, with no account.

Prefer Terminal? Run:

curl -fsSL https://raw.githubusercontent.com/tahoeliu/mdPreview/main/scripts/get.sh | bash

The installer checks a signed checksum before it installs anything.

2. Press Space in Finder

Select a .md file in Finder and press Space to preview it. mdPreview includes Quick Look support, so the preview is formatted too.

3. Open it in TextEdit or a browser

TextEdit shows the raw text. You can also drag the file into a browser, but most browsers still show plain text unless a viewer extension is installed. Both are workable for a quick look, but neither gives you a readable page or easy export.

Turning an AI answer into a PDF or Word file

ChatGPT, Claude and Gemini answers often arrive as Markdown. Save the answer as a .md file, open it in mdPreview, then choose File > Export to get a PDF with page numbers, a Word file with real heading styles, or a single-file web page.

Frequently asked

Is it free? Yes. MIT licence, no ads, no tracking.

Does it need internet? No. Your documents never leave your Mac.

Is it a Typora or MacDown alternative? Yes, for reading and simple editing. It is not a note-linking app or a code editor.

Will macOS block it? The app is ad-hoc signed. If macOS warns on first launch, open System Settings > Privacy & Security and choose Open Anyway.
