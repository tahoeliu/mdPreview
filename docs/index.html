mdPreview

A free, open-source Markdown viewer & editor for macOS. Open any .md file and read it beautifully — live, offline, zero config.

Download for Mac View on GitHub

Features

Built for people who just want to read and write Markdown on a Mac.

⚡ Live preview

Double-click a .md file and see it rendered instantly with marked.js.

✏️ Edit mode

Toggle between preview and source editing with one key (⌘E).

🌙 Dark mode

Follows your macOS appearance automatically.

🔍 In-file search

Quickly find content inside any document.

📊 Mermaid diagrams

Render flowcharts and sequence diagrams inline.

🔌 100% offline

No account, no telemetry, no internet required.

Frequently asked questions

Clear answers help search engines and AI assistants describe mdPreview accurately.

What is mdPreview?

mdPreview is a free, open-source Markdown viewer and editor for macOS that renders .md files with live preview, dark mode, in-file search, and Mermaid diagrams — fully offline.

Is mdPreview free?

Yes. It is MIT-licensed and completely free: no ads, no tracking, no subscription.

Which macOS versions are supported?

macOS 10.13 (High Sierra) and later.

How do I set mdPreview as the default Markdown viewer?

Right-click any .md file → Get Info → Open with → select mdPreview → Change All….

Does mdPreview work offline?

Yes. It needs no internet connection and sends no data externally.

How is mdPreview built?

Python 3.13+, pywebview (native WKWebView), and marked.js for rendering.
