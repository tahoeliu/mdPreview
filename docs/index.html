In mdPreview

Instant and light

Starts in about half a second. Double-click a file and it is already typeset. Nothing runs in the background.

Built to be finished

A hairline progress bar, “N min left”, section folding and Go to Heading keep a 5,000-word answer from feeling endless.

Edit like a document

Click anywhere and a formatting bar appears. Bold, headings, lists, links and tables, never a ** in sight.

Made for long answers

Restrained typography, and a few aids that appear only when a document is long enough to need them.

  • Progress bar and “N min left”, only in long documents
  • Collapse any section from the arrow in the margin
  • ⌘J jumps to any heading as you type a few letters
  • Long code blocks and tables show a head; one click shows all
  • Tables, math, Mermaid diagrams, footnotes and alerts render correctly
  • Reloads automatically when an AI agent changes the file

Click, then type

Documents open for reading. Put the cursor anywhere and a slim toolbar slides in; press Esc and it is gone.

  • Bold, italic, headings, lists, quotes and links from the bar
  • Insert a table, add or remove rows and columns
  • Paste from the web or a chat and get clean text (⇧⌘V)
  • Drop in images; they are saved next to the document
  • Prefer plain text? ⌘E switches to the source

Or one line in Terminal

Checks a signature and checksum first, and macOS shows no warning at all.

curl -fsSL https://raw.githubusercontent.com/tahoeliu/mdPreview/main/scripts/get.sh | bash

Prefer Homebrew? brew install --cask --no-quarantine tahoeliu/tap/mdpreview

Why the extra step? mdPreview is free software and doesn’t carry a paid Apple certificate. Requires macOS 13 or later.

Questions

Do I need to know Markdown?

No. Read it, click to edit with the toolbar, export. Source mode is there if you want it.

Is it really free?

Yes. MIT licensed, no account, no ads, no telemetry. A GitHub star helps others find it.

Does it send my documents anywhere?

Never. The only network request is an optional update check you can switch off. Remote images are not loaded until you allow them.

Why does macOS warn me the first time?

mdPreview is free and not signed with a paid Apple certificate, so a copy downloaded in a browser needs one confirmation: System Settings → Privacy & Security → Open Anyway. The Terminal install above avoids the prompt altogether.

Is it a Typora or VS Code replacement?

No. It is a focused reader with convenient editing and good sharing, not a writing studio or an IDE.

Spacebar preview in Finder?

Bundled with the app. If it does not appear, enable mdPreview Quick Look in System Settings → General → Login Items & Extensions → Quick Look.
